# Hotel Rural Latorrién de Ane — web

Sitio estático (sin build). Para publicar en Vercel: importa el repositorio, Framework Preset **Other**, sin comando de build, Output Directory `./` (raíz).

- `index.html` — maquetación y lógica (ES/EN, navegación por #/es/... y #/en/...).
- `content.js` — todos los textos, enlaces, puntuaciones e imágenes. Edita aquí.
- `assets/` — fotografías, logo y favicon. Para cambiar una foto, sustituye el archivo con el mismo nombre o cambia la ruta en `content.js`.
- `support.js`, `image-slot.js` — runtime necesario, no editar.

Antes de publicar: verificar puntuaciones y reseñas, el teléfono, y que las fotos enlazadas desde latorrien.es (Navarra, restaurante) sigan disponibles.
